# Release audits

Three distinct substantial audit/fix rounds were performed before publication.

| Round                                       | Findings and fixes                                                                                                                                                                                                               | Meaningful checks                                                                                                                                                                                                                                               |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Geometry, data and import safety            | Constrained procedural mesh bounds; preserved previous backups on unchanged saves; bounded and whitelisted imports; retained corrupt copies pending an explicit choice; added height and overlapping-opening notes.              | 15 unit/geometry tests covering rotated SAT, all four inward door swings, contact boundaries, rugs, fitting/snapping, extreme mesh dimensions, disposal, presets, complete undo/redo, independent copies, JSON restoration, invalid input and storage failures. |
| Interaction, accessibility and localization | Fixed effect cleanup that prematurely cancelled plan drags; increased secondary-text contrast; clarified labels; added a visible phone edit shortcut; preserved browser keyboard shortcuts; used unique SVG pattern identifiers. | Transactional and cancelled dragging, repeated numeric moves, undo/redo, save/reload, import cancellation, variant deletion/cancellation, comparison, exports, modal focus, EN/RU/KK checks and axe scans, reduced motion and actual no-WebGL fallback.         |
| Performance, mobile and release             | Improved camera fit on narrow screens; wrapped controls at 200% text; capped DPR; removed unnecessary server-renderer code from the browser bundle; arranged report figures together for clean printing.                         | Idle/offscreen frame checks, repeated renderer creation/cleanup, immediate page-exit saves, touch placement and visible controls, 60-piece stress, same-origin request checks, all materials/light/views, actual exported files and rendered PDF review.        |

The browser suite covers 320, 360, 390 and 414 px phone widths, their landscape orientations, 768/1024 tablet sizes, and 1440/1920 desktop sizes at DPR 1/2/3. Enlarged text is checked at 320/390/768/1440. This is Chrome/Chromium automation and viewport emulation; physical phones and Safari were not tested.

Fresh lockfile installation, typechecking, lint, unit tests, production build and the complete 12-case browser suite are release gates. The GitHub workflow repeats those checks before deploying the exact commit. Live key workflows are repeated after deployment. Working screenshots, exported files and traces remain local rather than being published as a large evidence bundle.
